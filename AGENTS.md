# Локальная сборка Capcon

Для обычной разработки на macOS/Linux используйте команды из `src/`:

- `./dev build` — собрать приложение; `./dev run` — запустить.
- `./dev test -p <crate> --lib` — проверить затронутый модуль.
- `./dev check -- -D warnings` — Clippy для приложения.

Эти команды сохраняют рабочий инкрементальный кэш UI и автоматически очищают
старые данные компилятора по `src/.cargo/dev-cache.toml`. Прямые вызовы Cargo
обходят очистку; используйте их для CI, release, мобильных и иных специальных
сборок. Проверки перед PR из CONTRIBUTING.md сохраняются.

При изменении управления кэшем запускайте `python3 src/scripts/test_dev.py`.
Подробности: `docs/BUILDING-CAPCON.md`.
